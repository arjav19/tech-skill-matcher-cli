    
# Software Engineer — Python & Web Platform
**Company:** CloudScale AI Innovations  
**Location:** Remote / Bengaluru, Karnataka  
**Employment Type:** Full-Time  


## Position Overview
We are seeking an engineer to build modern, data-intensive web applications. In this role, you will bridge the gap between high-performance Python backend services and interactive web interfaces.


## Technical Requirements:
* **Languages:** Extensive proficiency in **Python (3.10+)** and fundamental **SQL**. Knowledge of **JavaScript** is desirable.
* **Frameworks:** Hands-on experience with **FastAPI** or **Django**.
* **Databases:** Relational database experience with **PostgreSQL** or **SQLite**.
* **DevOps & Infrastructure:** Familiarity with **Docker** containers, **Git** version control, and deploying on **Linux** environments.
* **Testing:** Commitment to automated unit testing using **Pytest**.


## Nice to Have:
* Exposure to Vector Databases such as **ChromaDB** or semantic search concepts.
* Experience integrating **LLM** APIs (OpenAI or Gemini) for automated data workflows.
